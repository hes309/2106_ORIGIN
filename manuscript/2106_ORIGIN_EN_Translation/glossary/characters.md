## Usage Rules

1. **Character names in text**: Given name + Family name (English order)
   - Example: "Xingyu Lu walked to the terminal."
   - NOT: "Lu Xingyu walked..."

2. **First appearance**: "Xingyu Lu (陆星阈)" — English name + Chinese in parentheses
   - Subsequent: "Xingyu Lu" only

3. **Family name only**: Use family name when characters refer to each other formally
   - Example: "Mr. Lu" or "Director Shen"

4. **Organizations**: Always ALL CAPS in English text
   - Example: "ORIGIN calculated the probability."

5. **Technical terms**: English primary. Chinese in footnotes if needed for cultural context.

6. **No Chinese characters in body text** except:
   - First appearance parentheses
   - Footnotes
   - Chapter epigraphs (if any)

7. **Dialogue**: All English. No mixed languages.
   - If a character speaks Chinese in original, mark with: "[in Chinese]" or context only

## Naming Convention Rationale

- **Given name + Family name** follows Western naming order for English readers
- **Pinyin without tones** standard for Chinese names in English literature
- **Japanese names** follow standard Hepburn romanization (Given + Family name)
- **Single-name characters** (Eve, Hermann) remain as-is
- **Organizations** keep English names as established in original text (ORIGIN, NEXUS CORE, etc.)
