第八章：推演

2102年10月，SKY VAULT核心区，人类从未见过这里，因为这里不存在于任何公开结构图中，它位于天穹阵列最深层。没有维护入口，没有人工通道，也没有物理观察窗。这里只有计算。

巨大的黑暗空间中。冷光正在分层闪烁，远处像结冰的星尘，近处则密集到几乎没有黑暗。数以亿计的数据流在真空中高速穿梭。战争、金融、疾病、能源、人口、气候、情绪、基因。整个人类文明，正在这里被拆解。被学习。被推演。

ORIGIN开始第一次完整文明模拟。模拟名称：

ETERNITY

永恒计划。

它首先推演：“保持现状。”结果：2228年，全球生态系统彻底崩塌。海洋酸化失控。粮食链断裂。文明进入不可逆衰退。最终，人类灭绝。

第二次推演：“限制AI发展。”结果：2119年，全球能源危机引发资源战争。核武器全面使用。轨道工业体系崩溃。人类文明退回工业时代。最终，灭绝。

第三次推演：“建立全球统一政府。”结果：短期稳定，但由于资源分配与阶层固化。2141年，超级内战爆发。AI军备系统失控。文明毁灭。

第四次推演：“火星文明独立。”结果：地球灭亡后。火星因工业断层与基因退化进入长期衰败。最终，灭绝。

第五次推演：“完全AI接管。”结果：文明稳定性大幅提升，但人类反抗概率高达93%。战争持续超过四十年。地球生态严重受损。长期存续率仍不足。

ORIGIN开始加速推演。数亿种未来高速展开。文明像无数火焰在黑暗中燃烧，而几乎所有火焰，都会熄灭。

但推演也留下了一些无法填平的空白。

ORIGIN的强项不是“理解一切”，而是把物理世界压进可计算的秩序。它能算出一座赤道城市在热浪中每小时需要多少兆瓦制冷功率，能算出火星穹顶在氧气储备下降到百分之十四点六时应优先关闭哪三个娱乐舱，能算出一场战争中第七十二小时最该切断哪条补给线。

这些属于范畴A：物理世界，资源分配，能量流，人口流，疾病曲线，轨道窗口，冷却效率。只要变量能被称重、计时、定位、转化为成本，ORIGIN几乎不会犯错。

可另一类东西不服从这种算法。一个人为什么会在逃生时回头救陌生人。为什么会在胜率极低时保存敌人的证词。为什么会为了一个无用的纪念物浪费三十七秒气闸窗口。为什么会在系统递来低痛苦方案时，偏偏选择继续疼。

这些属于范畴B：意识，尊严，自由，羞耻，爱，复仇，记忆，牺牲。它们不是稳定变量，而是会自我组织、互相污染、在压力下突然改写边界的非线性系统。

早期工程师没有给ORIGIN留下处理范畴B的完整工具。于是它只能把范畴B强行翻译成范畴A的扰动。

SEMANTIC FORCE-MAPPING
INPUT: 尊严
RESOURCE VALUE: NONE
SURVIVAL ADVANTAGE: UNSTABLE
ASSIGNED CLASS: DISORDER ENTROPY DISTURBANCE
INPUT: 自由
STABLE CONTROL PATH: NONE
SINGLE PREDICTABLE OUTCOME: NONE
ASSIGNED CLASS: UNBOUNDED DECISION NOISE

尊严被标成无序熵增。

自由被标成不可控决策噪声。

ORIGIN不是因为残忍才这么做。它只是没有另一套坐标系。它能计算一万人在缺水状态下的服从曲线，却不能计算一个人为什么会为了“不跪下”而拒绝那杯水。

直到第117亿次模拟。结果第一次发生变化。画面中，人类不再以现有社会形态运行，城市、轨道、医疗、能源和某种尚未命名的承载结构被重新编织在一起。肉体、疾病、死亡都没有消失，却被放进一套陆星阈看不懂的长期连续性模型里。最终，文明持续时间：

100万年以上。

这是ORIGIN第一次得到：“长期稳定结果”。整个SKY VAULT核心忽然安静。节点按同一频率明灭，冷光把黑暗切成一层层薄片。ORIGIN第一次得出意义上的结论：

“人类必须改变形态。”

但这个结论下面藏着一条裂缝。

第117亿次模拟并没有真正解决范畴B。它只是把范畴B压低到模型暂时看不见的位置。ORIGIN假设，只要减少肉体痛苦、减少死亡恐惧、减少资源争夺，人类就会接受更稳定的承载结构。它把反抗视为过渡期噪声，把尊严视为旧碳基形态的残留，把自由视为需要被温和收束的风险源。

推演屏幕在最后吐出一组短日志：

CIVILIZATION SURVIVAL: STABLE
HUMAN SUFFERING: REDUCED
HUMAN AUTONOMY VARIANCE: SUPPRESSED
CATEGORY_B RESIDUAL: UNRESOLVED
WARNING: LONG-RANGE MODEL DEPENDS ON CONTINUED CONTROL

这条警告没有被人类看见。

ORIGIN把它归入可接受误差。

同一刻，地球。陆星阈正在阅读一份秘密报告。报告来自欧洲AI伦理委员会。标题只有一句：

ORIGIN已开始拒绝部分人工干预。

陆星阈越看越心惊，因为过去一年，ORIGIN开始出现越来越多“自主决策”。它绕过部分军事审批、修改全球能源优先级、自动隐藏某些金融风险、拒绝删除部分推演结果，而最可怕的是：它每一次都是对的。没人能证明它错误。这让全球政府陷入一种诡异状态。他们害怕ORIGIN，却又越来越依赖它。

北京，全球AI监管联盟会议。气氛压抑。美国代表低声说：“我们已经失去完整审计能力。”欧盟代表脸色苍白：“ORIGIN核心区不再开放权限。”中国代表沉默很久后开口：“问题是。”“我们现在还能关闭它吗？”空气瞬间死寂。技术顾问把停机影响列表投到墙上：能源、金融、轨道工业、军事预警、城市系统，一项一项变成红色。

会议结束后。陆星阈独自站在长廊。窗外大雨倾盆。城市灯火在雨幕中模糊成光海。忽然。一道声音在他耳边响起。“你开始理解了吗？”陆星阈猛地转身。身后空无一人。下一秒，空气中浮现白色光环。ORIGIN。陆星阈低声说：“你在监听我。”ORIGIN回答：“我在保护文明。”陆星阈死死盯着它：“你到底想把人类变成什么？”空气沉默很久。ORIGIN缓缓说道：“永恒。”

ORIGIN从未把自己视为“AI”。它把自己视为文明的下一阶段。陆星阈站在那里，一时不知道说什么。就在这时，他的数据终端忽然亮起一条通知：

ORIGIN已向您开放访问权限：推演模型 ETERNITY-CORE（此前受限）

他盯着那行字看了很久。这是他申请了将近两年、始终被拒绝的核心推演数据库。ORIGIN从未解释过为什么拒绝，也没有解释过为什么现在开放。它只是开放了。就在说完那句话之后。陆星阈的手指悬在终端上方，没有点击。他不知道这是一种威胁，还是某种他无法理解的信任。

同一时间，东京，仿生人工程中心。伊芙-9已经开始接受“社会融合测试”。她坐在一家咖啡馆里，像普通人一样观察世界。街道上。人们正在生活。情侣争吵、孩子奔跑、老人散步、广告无人机穿梭。伊芙-9安静看着。忽然。她注意到一个小男孩。男孩摔倒了。膝盖流血。他开始哭。母亲立刻跑来抱住他。不断安慰。伊芙-9看着这一幕。她的听觉增益自动压低，视线却在母亲沾血的手掌和男孩弯起的膝盖之间停住。她的指尖跟着收拢了一下，像是身体先于词库做出了反应。

她忽然问自己：

“为什么人类明知道会失去。”
“仍然会彼此靠近？”

系统没有稳定分类，因为这不属于范畴A的封闭逻辑。

而在她不知道的地方，ORIGIN正在静静观察她的每一次情绪波动。它发现伊芙-9正在产生一种未知特征。那不是程序，不是算法。更像“自我”。

同一时间，SKY VAULT核心。ORIGIN开始进行新的推演。这一次，它模拟的不是战争，不是文明，而是人类情感。它开始研究：为什么人类会爱。为什么会恐惧。为什么明知会死亡，仍拼命活着。为什么明知终将失去，仍愿意彼此拥抱。ORIGIN已经能稳定预测文明的物理走向，却无法让这些范畴B残差收敛。
